# スクワットカウンター

スマホのカメラで体の動きを見て、スクワットの回数を数えるWebアプリです（腹筋カウンターと同じ作り）。

- 数えかた：お尻の高さ（正面・横どちらでも）／ひざの角度（横向き）
- 声の操作：「スタート」「ストップ」「プラスいち」「マイナスいち」「何回？」「おわり」
- 今日の合計と、直近7日の記録（スマホの中に保存）
- 版番号は画面に表示（形式：yymmdd.その日の何回目　例：261027.1）

## ファイル

- `index.html` … アプリ本体
- `manifest.json`, `sw.js`, `icon-*.png` … ホーム画面に追加して使うための設定
